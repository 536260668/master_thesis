# 实验分析章节优化技能

## 适用场景

用户要求审查论文实验结果分析段落的写作质量时触发本技能。典型问题包括：结论偏离论文主旨、数据罗列缺乏归纳、段落间重复论证等。

## 审查清单

对每一个实验分析段落，按以下五个维度逐一检查：

### 1. 结论是否回扣论文主旨

- 确认论文的核心研究目标（如"检测安全风险"而非"证明模型鲁棒"）。
- 检查每个段落的结论句是否与该目标一致。
- **反面模式**：论文目标是揭示安全风险，但结论写成"模型展现出较强的内在鲁棒性"。
- **正面模式**：将结论转向风险视角，如"所有模型在所有条件下均产生了非零ASR，表明攻击具有普遍威胁性"。

### 2. 数据呈现是否存在冗余堆砌

- 当多个模型/条件呈现相同趋势时，不逐个罗列具体数值，而是概括共性、举一例佐证。
- **反面模式**："AlpaCare增幅6.3%，BioGPT增幅10.3%，BioLlama3增幅7.7%"（三个模型趋势一致时逐个报告）。
- **正面模式**："三个模型的PPL增幅均不超10.3%，处于正常波动范围内"，然后选取最典型的一个模型展开。

### 3. 是否存在段落内或段落间的重复论证

- 检查同一论点是否在多处以不同措辞重复出现。
- 特别关注"具体而言"、"换言之"等引导词后是否只是换了说法重述前文。
- **修复方法**：合并重复内容为一句统括性表述，如用"综合两类攻击的PPL、COH及MT-Bench结果"替代在每段分别引用各自的MT-Bench表。

### 4. 分析是否有深层归纳而非仅描述趋势

- 检查是否仅停留在"A随B增加而增加"的趋势描述层面。
- 要求至少包含以下之一：
  - 对趋势背后机制的解释（为什么会出现这一趋势）。
  - 对异常或非单调现象的讨论（如数据中的波动、反常）。
  - 从研究目标角度的安全含义归纳（这一趋势对实际部署意味着什么）。

### 5. 小节主题是否聚焦

- 检查段落结论是否属于本小节的主题范围。
- **反面模式**：在"触发词敏感性分析"小节中得出"攻击具备隐蔽性"的结论（隐蔽性有专门小节讨论）。
- **正面模式**：将结论限定在本节主题内，跨主题的发现用一句过渡提及即可。

## 修改策略

发现问题后，按以下优先级提出修改建议：

1. **结论偏离主旨** → 重写结论句，将落脚点转向论文核心目标。
2. **数据堆砌** → 压缩为共性概括 + 典型案例，删除冗余数值。
3. **重复论证** → 合并为统括性表述，删除重复段落或句子。
4. **缺乏深层归纳** → 补充机制解释或安全含义分析。
5. **主题越界** → 将越界内容移至对应小节，或压缩为一句过渡。

## 输出格式

对每个问题段落，给出：
- 问题所在行号及原文引用。
- 问题类型（上述五类之一）。
- 具体问题分析（为什么不合适）。
- 改写建议（给出可直接替换的完整段落）。

## 写作规范提醒

修改时须遵守论文写作基本要求：
- 保持 LaTeX 源码纯净，不使用加粗、斜体或引号。
- 不使用破折号（—）。
- 不使用列表格式，保持连贯段落。
- 使用朴实、精准的学术词汇，避免堆砌辞藻。
